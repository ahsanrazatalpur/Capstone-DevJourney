# Flutter aur Dart — Viva Notes

## Question 1: What is Flutter?

**Answer:**

Flutter Google ka ek **open-source UI framework** hai jiska use cross-platform applications banane ke liye hota hai.

Flutter ki madad se hum **Android, iOS, Web aur Desktop** ke liye ek hi codebase se applications develop kar sakte hain.

Flutter UI (User Interface), widgets aur app ka overall design handle karta hai.

---

## Question 2: What is Dart?

**Answer:**

Dart Google ki develop ki hui **programming language** hai.

Flutter applications Dart language mein likhi jati hain.

Dart app ki logic, functions, variables, classes aur business logic ko implement karne ke liye use hoti hai.

---

# Flutter aur Dart Mein Difference

| Flutter                                               | Dart                                              |
| ----------------------------------------------------- | ------------------------------------------------- |
| Flutter ek UI Framework hai.                          | Dart ek Programming Language hai.                 |
| UI aur Widgets provide karta hai.                     | Logic aur code likhne ke liye use hoti hai.       |
| Iska use cross-platform apps banane ke liye hota hai. | Is language mein Flutter app develop ki jati hai. |
| Flutter Dart language ko use karta hai.               | Dart Flutter ka base programming language hai.    |

---

# Simple Example

Agar app ko ek **car** samjhein:

* **Flutter** = Car ka body, design aur structure 🚗
* **Dart** = Car ka engine jo usse chalata hai ⚙️

Dono mil kar complete application banate hain.

---

# One-Line Viva Answer

> **Flutter ek cross-platform UI framework hai, jabke Dart ek programming language hai. Flutter app banane ke liye Dart language ka use karta hai.**
