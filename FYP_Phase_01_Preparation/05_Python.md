# Django aur Python — Viva Notes

## Question 1: What is Django?

**Answer:**

Django ek **high-level, open-source web framework** hai jo **Python** programming language par based hai.

Iska use secure, scalable aur maintainable backend applications banane ke liye hota hai.

Django hume built-in features provide karta hai, jaise:

* Authentication
* Admin Panel
* ORM (Object Relational Mapping)
* URL Routing
* Security Features
* Database Management

ProFinder mein maine Django ko backend banane ke liye use kiya hai, jahan APIs, authentication, business logic aur database management handle hota hai.

---

## Question 2: What is Python?

**Answer:**

Python ek **high-level, general-purpose programming language** hai.

Ye simple syntax, readability aur powerful libraries ki wajah se duniya ki sabse popular programming languages mein se ek hai.

Python ka use:

* Web Development
* Artificial Intelligence (AI)
* Machine Learning
* Data Science
* Automation
* Scripting
* Backend Development

jaise bohot se fields mein hota hai.

Django bhi Python language par hi develop kiya gaya hai.

---

# Maine Django Kyun Choose Kiya?

### • Secure Framework

Django built-in security features provide karta hai, jaise authentication, password hashing aur CSRF protection.

### • Rapid Development

Built-in features ki wajah se development fast hoti hai aur development time kam lagta hai.

### • REST API Support

Django REST Framework ke through mobile applications ke liye powerful APIs banana asaan hota hai.

### • Scalable Architecture

Django modular architecture provide karta hai, jis se future mein naye features add karna aur application ko scale karna asaan hota hai.

### • Built-in Admin Panel

Django automatically powerful admin panel provide karta hai jisse data aur users ko efficiently manage kiya ja sakta hai.

---

# Maine Python Kyun Choose Ki?

### • Simple aur Readable Syntax

Python ka code clean aur samajhne mein asaan hota hai.

### • Django Python Par Based Hai

Django use karne ke liye Python language ki zarurat hoti hai.

### • Large Community

Python ki bohot badi community aur documentation available hai, jis se development aur problem solving asaan hoti hai.

### • High Productivity

Python mein development comparatively fast hoti hai aur code kam likhna padta hai.

### • Future Scope

Python sirf web development tak limited nahi hai; AI, Machine Learning, Data Science aur Automation mein bhi extensively use hoti hai.

---

# Django aur Python Mein Difference

| Django                                        | Python                                                         |
| --------------------------------------------- | -------------------------------------------------------------- |
| Django ek Web Framework hai.                  | Python ek Programming Language hai.                            |
| Backend aur APIs banane ke liye use hota hai. | Programming aur application logic likhne ke liye use hoti hai. |
| Django, Python par built hai.                 | Python ke upar Django framework bana hua hai.                  |

---

# One-Line Viva Answer

> **Python ek programming language hai, jabke Django Python par based ek web framework hai. Maine Django is liye choose kiya kyun ke ye secure, scalable aur fast backend development provide karta hai, aur Python iski foundation language hai.**
