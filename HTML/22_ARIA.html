ARIA in html

ARIA stand for accesible rich internet application and it isused to give an extra information to screen reader so that blind person can understand and use web more easily


Example

x

<< simple button without text - Screen reader only read it as x button

X

<< simple btn without text but with arial label now screen reader read it as close menu btn so blind person easily understand what btn this is

Common ARIA attribute

  • aria-label - for give accesible label to an element
  • aria-hiiden - hide an element from screen reader
  • aria-expanded - indicate wether menu or section is expended
  • aria-disabled - tell reader that element is disabled
  • aria-required - tell reader that form field is required
