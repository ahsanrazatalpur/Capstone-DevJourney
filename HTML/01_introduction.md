Introduction : 

HTML stand for hyper text markup(to give structure to text using  h, p etc) language 

html is a standard language used to create and structure the web pages on the internet

What HTML does ?

HTML used to define webpages such as
 - heading
 - paragraph
 - images and videos
 - links
 - buttons 
 - links

 It tell browser what content to show and how it is organize it doesnot make it styling or functional



 Example syntax :

 <!DOCTYPE html>    <!-- Declare HTML5 documents-->
<html> <!-- root tag -->
<head> <!-- contain meta information that doesnot show on browser-->
    <title>My First Page</title> <!-- title of the program-->
</head> <!-- head close-->
<body> <!-- content start that show on browser-->

    <h1>Hello World</h1>
    <p>This is my first HTML page.</p>

</body> <!-- end of the body-->
</html> <!-- end of the root tag-->
