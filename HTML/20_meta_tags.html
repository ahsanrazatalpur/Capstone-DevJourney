Meta Tags in HTML

Meta tags in html is a special tag used in head tags that are not visible on browser but are important information about webpage to browser and SEO but they are not visible all meta tags are written under head tags

Common meta tags are

  • Charset = tell browser to support all char of eng , urdu etc
  • viewport = make website responsive to properly fit on mobile
  • Description SEO = show summary in Google search result
  • Author = Define page creator
