Semantic Tags

Semantic tags are those who describe the meaning and purpose of the content , they help browser , search engine and screen reader to understand the structure and content of the web pages

Here is the list of Semantic Tags

  • header - For head cell
  • nav - For navbar
  • main - For main content
  • footer - For footer content
  • section - For create section
  • article - For create article
  • h1 to h6 - For heading
  • p - For paragraph
  • strong - make text bold
  • em - make text emphasis or itlaic
  • figure - group image and diagram
  • figcaption - define caption for figure
  • detail - for epandable content
  • summary - define heading for detail content
  • time - represent date and time
  • address - define content information
