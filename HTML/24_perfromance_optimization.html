Performance optimization

Performance optimization is the process of make websites load faster and more effecient

Common Techniques

  • Optimized Images : used compressed or small size image to load our web faster
  • Minify CSS and JS : remove unnecessary css and js to redduce file size
  • External CSS and JS sheet : Insetad of large css js used external css and js sheet
  • Reduce http request : reduce images , vidoes , css and js to file to make fewer requrest to server
  • Enable browser catching : store web file in user browser so they dont need to downlaod again on every visit
  • Load JavaScript effeciently : Use defer attribute to load HTML first
  • Use responsive Images : load image and make image of user device screen size Insetad of large size
