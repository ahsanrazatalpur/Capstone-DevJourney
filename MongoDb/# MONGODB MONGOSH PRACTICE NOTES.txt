# MONGODB MONGOSH PRACTICE NOTES

==================================

# BASIC COMMANDS

1. OPEN MONGOSH

---

Command:
mongosh

Meaning:
Starts MongoDB Shell and connects to MongoDB server.

2. SHOW DATABASES

---

Command:
show dbs

Meaning:
Displays all available databases.

3. SWITCH / CREATE DATABASE

---

Command:
use LaarDb

Meaning:
Switches to LaarDb database.
If database does not exist, MongoDB creates it after inserting data.

4. SHOW COLLECTIONS

---

Command:
show collections

Meaning:
Displays all collections inside current database.

5. CREATE COLLECTION

---

Command:
db.createCollection("Student")

Meaning:
Creates a new collection named Student.

6. RENAME COLLECTION

---

Command:
db.Student.renameCollection("Students")

Meaning:
Renames Student collection to Students.

7. FIND DOCUMENTS

---

Command:
db.Students.find()

Meaning:
Displays all documents from Students collection.

8. DROP COLLECTION

---

Command:
db.Sample.drop()

Meaning:
Deletes Sample collection completely.

9. DROP DATABASE

---

Command:
db.dropDatabase()

Meaning:
Deletes current database completely.

10. INSERT ONE DOCUMENT

---

Command:

Age : 22,
Department : "Computer Science",
email : "[ahsanraza@gmail.com](mailto:ahsanraza@gmail.com)"

# VALIDATION / SCHEMA COMMAND

13. CREATE COLLECTION WITH VALIDATOR

---

Command:
db.createCollection("CS", {
validator : {
$jsonSchema : {

```
     bsonType : "object",

     required : ["name", "age"],

     description : "name and age must be required",

     properties : {

        name : {
           bsonType : "string",
           minLength : 8,
           maxLength : 20,
           description : "Name must be required"
        },

        age : {
           bsonType : "int",
           minimum : 2,
           maximum : 9,
           description : "Age must be required"
        }
     }
  }
```

}
})

Meaning:
Creates CS collection with schema validation rules.

# IMPORTANT MONGODB CONCEPTS

Database:
Container that stores collections.

Collection:
Group of documents (similar to table).

Document:
Single record stored in MongoDB.

db:
Represents current database.

insertOne():
Insert single document.

insertMany():
Insert multiple documents.

find():
Display documents.

drop():
Delete collection.

dropDatabase():
Delete current database.

renameCollection():
Rename collection.

$jsonSchema:
Used for validation rules.

mongosh:
MongoDB command line shell.
