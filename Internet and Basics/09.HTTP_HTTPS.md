HTTP and HTTPS : HTTPS and HTTPS are protocol (rules) of communication between browser and server

HTTP : stand for hyper text transfer protocol 
when we visit website http decide how our browser request a data and how server send back or response data 

Exampple :
           https://google.com

HTTP is not incrypted so other can read it 


HTTPS : Hyper text transefer protocol secure 
HTTPS encrypt the data between browser and server


Example flow: 


HTTP
Browser → Request → Server
Browser ← Response ← Server

Data is sent without encryption.

HTTPS
Browser → Encrypted Request → Server
Browser ← Encrypted Response ← Server
