Position In CSS

Position : is a property that decide / control the position of the element

There are 5 type of positions in CSS

1. Static (Default)

Static position is a default position of the element , Top, bottom , left and right doesn't work on it


2. Relative Position

Relative Position is a posiition where content can move from original position with the help of top , bottom, left and right

note : The original position will be reserved , the elemnt will be moved to new position but his old position still reserved , occupied or fill becuase browser consider it is still on same place his old position will be free no other element can fill that position Normal: [A][B][C] Relative (B moved right): [A][ ][C] ↘ [B] [B] visually move ho gaya.
