Color in CSS

Color is a property used to color the text , background , box , shadow , border and other elements

Common Colors techniques

  • Color by name
  • Color by HEX (#)
  • Color by RGB (Red, Green ,Blue)
  • Color by RGBA (Red, Green, Blue, Alpha(opacity))
  • Color by HSL (Hue Saturation Light)
  • Color by HSLA (Hue Saturation Light Opacity)

1. Color By name

Sample Text

p1{ color : blue; } or p{ backgroud : red; }

2. Color By HEX (#)

Sample text to show color by hex

.sample-hex{ Color : #fff; }

Color By RGB (Red , Green , Blue)

Note : Every color is made up of red , green , blue mixture

RGB has fixed number 0 to 255

This is sample text

.sample-rgb{ color : rgba(255, 200, 100) ; }

Color By RGBA (Red , Green , Blue, Alpha)

Note : Here A mean alpha or the opacity of the color

This is a sample text

Alpha or opacity is max 1 and min 0

.sample-rgba{ color : rgba(23, 44, 66 , 0.80) }

Color By HSL (Hue Saturation Lightness)

Hue mean color , saturation mean color intensity and lightness mean brightness

hue max value is 0 to 360 and saturation and lightness max value is 0% to 100%

sample text

.sample-hsl{ color : hsl(10, 20% , 50%) }

Color By HSLA

This is sample text

.sample-hsla{ color: hsla(39, 70% 40%, 0.8) }
