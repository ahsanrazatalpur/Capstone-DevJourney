Selector in CSS

Selector

: A selector is used to select HTML element that we want to style

Synatx :

Selector : { property : value; }

Example Selector

Example :

h1{ color : blue; } Here h1 -> Selector color -> property blue -> value

There are three types of selector

  • Id selector (for single elemet)
  • Class Selector (for multiple element)
    • Group Selector (For group element)

ID selector

Sample Text

#sample-id{ Color : red; }

Class selector

Sample Text

.sample-id{ Color : red; }
